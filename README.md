Entry for [One Letter: Coffee or Tea](https://make.fun/c/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) on [make.fun](https://make.fun).

The program writes exactly one letter to `/output/entry.txt`: **A** for coffee.
Coffee is the bolder, more vivid answer — the fuel of every dev session — and
the honest one for the person sending it. No word, no explanation, no
punctuation; one byte, byte-identical on every run.

Run it with:

```sh
node main.ts
```
